# Dotfiles

Managed with [chezmoi](https://www.chezmoi.io/).

Cross-platform dotfiles with support for macOS and Linux, featuring conditional configuration based on OS and machine type (work/personal). Uses templating for dynamic values and integrates with Bitwarden for secrets management.
